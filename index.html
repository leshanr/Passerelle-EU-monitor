Fetch the latest pulls the newest digest straight from the repository. It works when this page is opened from a web address. If you opened it from a file on your computer, your browser will block that, so paste instead.

To paste one in, or to load a digest someone sent you:

  1. Open the digests folder and pick the newest .json.
  2. Tap Raw, select all, copy.
  3. Paste below and press Load.
